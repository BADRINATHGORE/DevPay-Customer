Secure Digital Banking Application – Project (Ongoing)

Project Overview

DevPay is an ongoing digital banking application developed as an academic project to demonstrate real-world banking functionalities. The system includes a customer mobile application and a bank/admin web panel, focusing on secure authentication, account management, and transaction handling.
